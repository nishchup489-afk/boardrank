Project Methodology

How Rankings Are Calculated

This page describes the deterministic rules used to calculate the published rankings.

This ranking is independently calculated for this website and is not an official board ranking.

Current Ranking Priority

  1. GPA descending
  2. Total marks descending
  3. Physics descending
  4. Chemistry descending
  5. Mathematics descending

Ties are ordered by the next available priority field. If all priority values match, the production pipeline should apply a documented deterministic fallback rather than silently creating unstable results.

Data Quality / Corrections

Incomplete, duplicated, or invalid result rows should be held out of public ranking until reviewed. The production workflow should keep validation reports so corrections can be made transparently before static JSON is published.

Prototype Scope

The current frontend uses clearly fictional mock students, rolls, schools, and marks. The education board does not issue or endorse these rankings.
